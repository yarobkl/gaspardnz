# Instructions pour les agents de developpement

- Respecter le code, les regles metier, le schema de donnees et le design existants. Examiner avant de modifier.
- Pour une fonctionnalite non triviale, une revue d'architecture ou un refactoring, consulter le skill local `.agents/skills/pragmatic-design-patterns/SKILL.md` et suivre sa procedure.
- Ne pas ajouter de pattern, couche ou dependance sans besoin concret.
- Ajouter/verifier les tests adaptes et communiquer leurs resultats reels.
- Ne pas modifier les secrets, les droits d'acces ou les parametres de production et ne pas declencher de deploiement sans demande explicite.
